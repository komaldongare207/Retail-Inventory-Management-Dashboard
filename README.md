# Retail-Inventory-Management-Dashboard
This project presents a Retail Inventory Management Dashboard developed using Power BI to analyze sales, profit, inventory, store performance, regional performance, and promotional impact. The dashboard provides interactive insights into key business metrics and helps identify sales trends, profitable regions, store-wise performance, and inventory status for better retail decision-making.
## Project Objective
To use data analytics and visualization techniques to monitor retail sales, profitability, inventory levels, and store performance through an interactive Power BI dashboard.
## Key Features
- Sales & Profit Performance Analysis
- Profit Margin Analysis
- Inventory Remaining Analysis
- Sales by Category
- Profit by Region
- Store-wise Units Sold Analysis
- Sales Trend Analysis
- Promotion Impact Analysis
- Interactive Filters & Slicers
- KPI Cards for Business Metrics
## Tools & Technologies
- Power BI
- Power Query
- DAX
- Microsoft Excel / CSV
- Data Modeling
- Data Visualization
